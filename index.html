藍芽與 Inverter 交握狀態機

驗證藍芽連線、`*IDN?` 設備查詢，以及雙引腳（P1_2 == 0 & P3_5 == 0）之暫時停止判斷與例外處理。

P1_2 == 0 & P3_5 == 0"} B -->|OK| H[正常運作
開始輪詢] C -->|Yes| D[設定頁：按鈕設為 ON] C -->|No| G D --> E{"[退出暫時停止]
